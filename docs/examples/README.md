# Примеры итоговых отчётов

Все три файла сгенерированы **живым стеком** (backend Spring Boot +
PostgreSQL + seed-каталог) - не собраны вручную.

## Файлы

| Файл                  | Формат                  | Что внутри                                                                                                                                                                                                                                                                                       |
|-----------------------|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `example_report.pdf`  | PDF (Apache PDFBox 3.x) | Человекочитаемый отчёт: титул с пометкой о предварительной оценке, параметры объекта, выбранные решения, состав оборудования, расчёт экономики трёх сценариев с Δ к базовому, имитация 2D с KPI и растеризованной схемой склада, ограничения, источники данных, даты расчётов, финальная пометка |
| `example_report.xlsx` | Excel (Apache POI XSSF) | Машиночитаемые таблицы - 7 листов: Сводка, Параметры, Решения, Оборудование, Экономика (числовые ячейки), Допущения, Источники (ТТХ решений с провенансом)                                                                                                                                       |
| `example_report.csv`  | CSV                     | Плоская таблица `section;key;value;unit;source`: UTF-8 с BOM, разделитель «;», десятичная запятая (совместимость с Excel/LibreOffice)                                                                                                                                                            |

## Исходный проект

- Проект **id 7 «Демо: Пиковая нагрузка - успех»** (владелец - демо-аккаунт
  `user`, seed; состав - АТ-Паллета 2500 × 4 + АТ-Штабелер 1000 × 2).
- Состав покупки и RaaS - решения тестовых фикстур: АТ-Паллета 2500 × 4 +
  АТ-Штабелер 1000 × 2 (6 единиц).
- Экономика рассчитана по всем трём сценариям
  (base / purchase / raas, `economic-model-1.0`); имитация 2D
  запущена, схема в PDF встраивается автоматически (серверный рендер
  из kpi_json при отсутствии сохранённой клиентом схемы).
- Допущения расчёта - дефолты каталога (assumptions.md §22–23),
  переопределений нет; горизонт 5 лет.

## Как воспроизвести

1. Поднять стек одной командой (README корня):
   `docker compose up -d --build` - поднимутся db, backend, frontend,
   seed загрузит полный каталог (187 решений) и демо-аккаунты
   `user`/`useruser`, `admin`/`adminadmin`.
2. Войти как `user` → открыть проект «Демо: Пиковая нагрузка - успех»
   (или любой склад с рассчитанной экономикой).
3. «Экономика и сравнение» → «Рассчитать и перейти к дашборду»
   (если расчётов ещё нет), при желании - «Имитация 2D и KPI» →
   «Сохранить схему».
4. «Экспорт отчёта» → кнопки «Скачать PDF» / «Скачать Excel (XLSX)» /
   «Скачать CSV» - файлы идентичны приведённым (отличие - только
   дата генерации в титуле и штамп в имени файла).

Эквивалентно через API (Bearer-токен входа):

```
POST /api/projects/7/exports        {"format":"pdf"}   → 201, id выгрузки
GET  /api/projects/7/exports/{id}                      → файл
```

Полный путь проверки страницы экспорта -
`scripts/verify_export_ui.py` (Playwright, живой стек).
