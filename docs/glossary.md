# Глоссарий

Термины и сокращения проекта. Источники - исходные материалы организатора
(раздел «Термины и сокращения»), уточнения организатора; термины
проекта - по сложившемуся употреблению в `docs/*` и `docs/requirements/*`.

## Базовые термины

| Термин | Определение                                                |
|--------|------------------------------------------------------------|
| SKU    | единица номенклатуры товара                                |
| CAPEX  | капитальные затраты на приобретение и внедрение решения    |
| OPEX   | операционные затраты на эксплуатацию решения               |
| ROI    | отношение полученного экономического эффекта к инвестициям |
| TCO    | совокупная стоимость владения решением                     |
| WMS    | система управления складом                                 |
| ERP    | система планирования ресурсов предприятия                  |
| API    | программный интерфейс обмена данными                       |
| MVP    | минимально жизнеспособная версия продукта                  |
| БАС    | беспилотная авиационная система                            |
| БРС    | беспилотная роботизированная система                       |

## Отраслевые термины

| Термин                                          | Определение                                                                                                                                                                        | Источник       |
|-------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------|
| СУБД                                            | система управления базами данных (реляционная или документо-ориентированная)                                                                                                       | уточнения организатора |
| AMR (Autonomous Mobile Robot)                   | автономный мобильный робот, использующий систему навигации и датчики для самостоятельного движения по произвольным и заданным маршрутам без магнитных лент и рельсов               | уточнения организатора |
| FMR-робот (Forklift Mobile Robot)               | автономный вилочный погрузчик или штабелер - беспилотная складская машина, автоматически перемещающая паллетные грузы                                                              | уточнения организатора |
| RaaS (Robots as a Service, «роботы как услуга») | сценарий финансирования роботизации: аренда роботов или оплата за использование вместо покупки; логика финансового расчёта формируется участниками самостоятельно                  | уточнения организатора |

## Термины проекта

| Термин       | Определение                                                                                                                                                                                                                                                    | Употребление                                                                     |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| TRL (УГТ)    | Technology Readiness Level - шкала готовности технологии 1–9; в CSV каталога поле «УГТ», значения 3–9 (3 - proof of concept, 9 - серийное производство)                                                                                                        | `solution.trl`, assumptions.md §8                                                |
| EAV          | Entity–Attribute–Value - модель хранения переменного набора характеристик: справочник метаданных (`characteristic_type`, `parameter_type`) + таблицы значений (`solution_characteristic`, `object_type_parameter`) с инвариантом «ровно одно value_* NOT NULL» | data_model.md §2.3–2.4, §3.2                                                     |
| BFF          | Backend-for-Frontend - промежуточный слой: Next.js управляет сессией пользователя и проксирует запросы к Spring Boot, валидирующему JWT                                                                                                                        | architecture.md                                                    |
| DTO          | Data Transfer Object - объект переноса данных между клиентом и API; сущности JPA наружу не отдаются, только DTO                                                                                                                                                | architecture.md §3                                                                |
| ТТХ          | тактико-технические характеристики решения (грузоподъёмность, масса, габариты, точность позиционирования, мощность зарядки, уровень шума и др.)                                                                                                                | requirements/catalog.md, assumptions.md §3                                       |
| Q&A-сессия   | сессия вопросов и ответов организатора хакатона; уточнения обязательны к учёту в моделях и допущениях                                                                                                                                                          | уточнения организатора, requirements/catalog.md, docs/backlog/closed_questions.md (группа 1) |
| Seed         | идемпотентный скрипт наполнения БД данными организатора (CSV + XLSX); повторный запуск не меняет счётчики                                                                                                                                                      | scripts/seed/, data_model.md §7                                                  |
| Дедупликация | приведение строк CSV 223 → 187 решений по `external_id` (23 группы дублей); дубли трактуются как альтернативные предложения                                                                                                                                    | data_model.md §5.1 / assumptions.md §9                                           |
