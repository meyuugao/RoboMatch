# Пользовательский целевой путь

## Таблица шагов

| Этап                                   | Результат                                                                                                                                                                          |
|----------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Шаг 1. Выбор отрасли и объекта         | Пользователь выбирает склад, аэропорт, медицинское учреждение либо другой тип объекта, реализованный командой. Для базовых типов объектов доступны демонстрационные наборы данных. |
| Шаг 2. Формирование параметров проекта | Пользователь указывает характеристики объекта и процессов вручную либо загружает Excel/CSV-файл. Система проверяет заполненность, формат и допустимые диапазоны значений.          |
| Шаг 3. Подбор решений                  | Платформа определяет применимые типы роботизации, показывает конкретные продукты и объясняет причины включения или исключения решения.                                             |
| Шаг 4. Сравнение                       | Пользователь сопоставляет решения по унифицированным техническим, эксплуатационным и экономическим характеристикам.                                                                |
| Шаг 5. Расчёт экономики                | Платформа рассчитывает состав оборудования, CAPEX, OPEX, TCO, годовой эффект, срок окупаемости и ROI, а также показывает исходные предпосылки и формулы.                           |
| Шаг 6. What-if анализ                  | Пользователь меняет ключевые параметры и сравнивает базовый сценарий и альтернативные сценарии роботизации в одной таблице.                                                        |
| Шаг 7. Визуализация                    | Платформа отображает работу роботов на 2D-схеме объекта и связанные KPI. Визуализация должна подтверждать расчёт, а не быть только декоративной анимацией.                         |
| Шаг 8. Сохранение и экспорт            | Пользователь сохраняет проект и выгружает результаты в PDF и Excel либо в эквивалентные открываемые форматы.                                                                       |
