# Журнал закрытых вопросов

Журнал ведёт историю всех вопросов, поднимавшихся при разработке
RoboMatch, и их закрытия к финальной сдаче (150 пунктов: Q-1…Q-33,
TD-1…TD-80, DD-1…DD-17, BL-1…BL-20). Каждый пункт закрыт одним из
вердиктов: «решён реализацией» (код/документация), «решён правкой
финальной зачистки» (этой серией), «закрыт ответом из конкурсных
материалов», «осознанная граница MVP» (задокументирована), «вне
объёма» (не влияет на продукт), «перенесено» (в mvp_scope.md).
Хронология пополнения - в конце.

**Продукт передан; новые вопросы не регистрируются.**
